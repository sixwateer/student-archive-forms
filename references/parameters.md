# 参数详解与模板结构要求

## 配置文件

`scripts/config.example.json` 里的每个键都对应一个同名的命令行参数（`group_mode` → `--group-mode`）。命令行参数优先于配置文件。`--config` 里的未知键会被忽略，可放 `_说明` 之类注释键。

```bash
python scripts/generate.py --config 我的配置.json --group-mode college --margin-cm 1.5
```

## 核心参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--source` | 必填 | 学生名册 `.xls` / `.xlsx`，读第一个 sheet |
| `--template` | 必填 | 纸质表模板 `.xlsx` |
| `--out` | 必填 | 输出目录，自动创建 |
| `--header-row` | 3 | 名册表头所在行号（1 起）。导出系统常在标题后空一行，故为第 3 行 |
| `--template-header-row` | 1 | 模板表头行 |
| `--template-data-row` | 2 | 模板首个数据行，仅用于取边框/字体样式 |
| `--footer-gap` | 3 | 示例数据区与页脚之间的最小空行数，用于自动区分两者 |
| `--group-mode` | `college-level` | 见下表 |
| `--name-prefix` | 名册文件名 | 输出文件名前缀 |
| `--margin-cm` | 2.0 | A4 四周边距；可打印宽度 = 21 − 2×边距 |
| `--border-style` | `thin` | 表格实线：`thin` 全细黑线（默认，外框与内线一致）；`medium`/`thick` 外框加粗；`none` 沿用模板边框 |
| `--note-width` | 9.0 | 备注列目标宽度（列宽单位），有富余时才放宽 |
| `--stats` | 关 | 打印 学院×层次 人数与占比 |
| `--zip-by-level` | 关 | 按层次后缀把生成文件打成 zip |
| `--exclude` | 空 | 逗号分隔的层次显示名，跳过不生成 |
| `--grade` | 空 | 年级，如 `2025` / `2025级`；自动识别年级列并筛数据，同时写进文件名 |
| `--grade-column` | 自动探测 | 年级列名，可逗号分隔多列；默认依次找 `当前所在级 / 年级 / 入学年份 / 所在级` |
| `--level` | 空 | 只保留的层次显示名（`本科` / `专升本` / `本科,专升本`）；留空 = 全部 |
| `--college` | 空 | 只保留的学院，逗号分隔或 JSON 数组 |
| `--class` | 空 | 只保留的班级，逗号分隔或 JSON 数组 |
| `--exclude-ids` | 空 | 排除学号，逗号分隔或 `@文件路径`（每行一个） |
| `--list-filters` | 关 | 只列出可筛选的年级/层次/学院/班级及人数，不生成文件 |
| `--log` | `<out>/_生成报告.txt` | UTF-8 报告路径 |

## 先筛选再生成

所有筛选参数可叠加，顺序为：年级 → 层次 → 学院 → 班级 → 排除学号 → `--exclude`。每一步都在报告里写明剔除行数，最后给出「筛选后 N 人 / M 个班」。

```bash
# 先看名册里有什么
python scripts/generate.py --source 名册.xls --header-row 3 --list-filters

# 只要 2025 级本科
python scripts/generate.py --config 我的配置.json --grade 2025 --level 本科

# 只要某学院某几个班
python scripts/generate.py --config 我的配置.json --college 商学院 --class '会计本2026-1,会计本2026-2'
```

- **年级**：`year4()` 从 `2025级 / 2025-09 / 2025` 里取 4 位年份；多个年级列取「任一命中」。名册无年级列时只用于命名，报告会提示。
- **层次**：匹配 `--level-map` 映射后的显示名，也兼容原始值（`普通本科` 也能匹配 `--level 普通本科`）。写 `全部` / `all` 等价于不筛。
- **学院 / 班级**：精确匹配去空格后的字符串；值里含逗号时用 JSON 数组，如 `--college '["A学院","B学院"]'`。
- **配置文件**里对应的键是 `grade`、`grade_column`、`level`、`college`、`class`、`exclude_ids`（脚本内部映射到 `level_filter` 等 dest，无需关心）。
- 筛选后写出 `_筛选条件.json` + `_筛选信息/筛选后名册.xlsx`（表头在第 1 行）。`verify.py` 读到前者会自动改用子集核对，无需改命令；`--ignore-filter` 可强制按全量名册校验。
- 筛选后只剩一种层次时，`--stats` 的交叉表会自动补 0 列（历史 bug 已修），不会报 `KeyError`。

## 名册列映射

默认值针对常见教务导出：

| 参数 | 默认列名 |
|---|---|
| `--id-column` | 学号 |
| `--name-column` | 姓名 |
| `--level-column` | 培养层次 |
| `--college-column` | 上课院系 |
| `--class-column` | 班级 |
| `--class-code-column` | 班号（排序用；不存在时按班级名排） |

模板表头到名册列的映射默认写在 `generate.py` 的 `DEFAULT_COLUMN_MAP`：

```
序号→自动编号, 姓名→姓名, 学号→学号, 学院→上课院系, 班级→班级,
是否存档→留空, 备注→留空
```

列名不同时不必改脚本，用 `--column-map` 覆盖，例如模板写「所属学院」：

```bash
--column-map '{"所属学院":"院系名称"}'
```

其中 `__index__` = 自动序号，`__blank__` = 留空。模板表头出现未映射的名字时，该列会被留空，不报错。

## 分组模式对照

以 5612 人 / 126 班 / 9 学院、层次为「本科 / 专升本」为例：

| `--group-mode` | 文件数 | sheet 总数 | 文件名样例 |
|---|---|---|---|
| `college-level` | 17（未来科技学院无专升本，只有 1 个） | 126 | `2026级档案纸质表格-商学院-本科.xlsx` |
| `college` | 9 | 126 | `2026级档案纸质表格-商学院.xlsx` |
| `level` | 2 | 126 | `2026级档案纸质表格-本科.xlsx` |
| `class` | 1 | 126 | `2026级档案纸质表格-全部班级.xlsx` |

`--zip-by-level` 只在 `college-level` 下最有意义，产出：
`…本科(9个学院).zip` 与 `…专升本(8个学院).zip`。

## 模板结构要求

脚本按以下规则读模板，**不硬编码行号**：

1. 第 1 行（`--template-header-row`）连续非空单元格 = 表头。
2. 表头以下所有非空单元格 = 页脚，记录「列号 + 相对首个页脚行的偏移 + 文本」，生成时原样放到最后一个数据行之后。
3. 数据区样式取 `--template-data-row` 首个单元格；若模板没有边框，自动补细边框。
4. 表头居中加粗样式取表头首格，页脚样式取首个页脚格。

5. 模板数据区常被填入示例学生（本场景里 A2:B18 有 17 行示例）。脚本按**最大行间隔**切分：
   示例区（第 2–18 行）与页脚区（第 50–55 行）之间有 31 个空行，超过 `--footer-gap=3`，
   于是只把页脚区带过去，示例数据被忽略。生成报告会写明「模板页脚单元格数 / 已忽略示例数据单元格」。
   若两者之间没有空行，无法自动区分，此时需清空模板示例数据或调整 `--footer-gap`。

典型模板（本场景）：`序号|姓名|学号|学院|班级|是否存档|备注`，第 2–49 行为带细边框的空数据行，D50:D55 为
`应收    份 / 实收    份 / 接收人： / 移交人： / 核查人： / 时间：`。`verify.py` 用同样的
`--footer-gap` 逻辑定位页脚，两处参数要保持一致。

## A4 版式算法

```
可打印宽 = 21cm − 2 × margin_cm
列宽单位上限 = 可打印宽 / 0.185
单列所需单位 = 文本宽度 / 0.185 + 1.2(留白)
文本宽度：宋体 11pt 全角字符 0.388cm，半角 0.194cm
```

按「表头 + 全量数据 + 页脚」的最长字符串算每列需求；若总和超上限，依次压缩
`备注 → 是否存档 → 序号 → 姓名`（下限为该列表头宽度）；有富余时把备注放宽到 `--note-width`。

打印参数：A4 纵向、`fitToPage=True`、`fitToWidth=1`、`fitToHeight=0`、水平居中、每页重复第 1 行、
`print_area = A1:{末列}{页脚末行}`。

## 常见改法

- 只出某个层次：加 `--exclude 专升本`
- 边距改成 1.5cm：`--margin-cm 1.5`（列宽会自动重算）
- 名册换了列名：改 `--column-map`，不要改脚本
- 模板换了列数：`--template-header-row` + `--column-map` 配合，脚本自动适配列数
