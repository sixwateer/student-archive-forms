学生档案表生成器 · 操作指引

把教务处导出的学生名册，变成可以直接拿去打印的分班档案表。

网页版：双击 HTML，零安装 exe 版：双击 exe，自动开浏览器 两者结果完全一样

1三步上手

  1. 选名册：第 1 步选 学生基本信息.xls/.xlsx。稍等自动读取，并出现「名册自检」。
  2. 挑数据：默认全校都出。想只整理某一届 / 只要本科 / 只挑几个学院班级，在下面勾一勾。
  3. 生成：看实时统计（已选 X 人 / Y 个班 / 将生成 Z 个文件）→ 点绿色「开始生成」→ 等几秒自动下载。

2四个筛选条件（可叠加）

条件作用小技巧
年级 选「2025级」= 入学年份/届别为 2025；选「全部年级」只按下面条件筛 下拉只列名册里真实存在的年份
层次本科 / 专升本（专科）/ 一起出专升本就是平时说的专科
学院勾选要出的学院搜索框输入关键字（如「计算机」）秒搜，出现「全选匹配」一键勾上
班级勾选要出的班级搜索框输入关键字（如「机器人」「会计」）秒搜，出现「全选匹配项」一键勾上
重要联动：选了「年级 / 层次」后，符合条件的班级会自动勾选、其余置灰；想手动加回直接勾上即可。切换年级/层次会实时刷新学院人数和班级人数。

3搜索怎么用（定位「机器人」这类班级）

  1. 在班级搜索框输入关键字（班级名里的字，不是学号），如「机器人」。
  2. 列表立刻只剩匹配项，第一个匹配会被黄底高亮并自动滚到可见位置。
  3. 点「全选匹配项」一键把搜到的班级全勾上；「清空匹配项」反选。
  4. 学院搜索框同理，用来在几十个学院里快速定位。

4名册自检（读取后自动出现）

  • 红字：必须先修名册才能生成（如重复学号，会导致人数偏多、同一人出多张表）。
  • 黄字：提醒（如某些单元格为空）。
  • 绿字：可放心生成。

建议每次生成前看一眼自检结果。

5高级设置（一般不用改）

  • 预设模板：点一下套用最常用场景 —— 本科·按学院分、专升本·按学院分、全部·按层次分、全部·只按学院分、全部班级一个文件。
  • 分组方式、文件名前缀、排除个别学号、更换模板文件，按需调整。

6合并发给别人

已经生成了按学院拆开的多个 .xlsx 或「本科(9学院).zip」「专升本(8学院).zip」？

拉到界面最下面「合并成一个大 ZIP」，一键合成一个 档案表成果-合并全部.zip，整体发出去，对方解压就能拿到全部表格。

7打印

打开下载到的 Excel → Ctrl + P → 打印范围选「整个工作簿」，一次打完里面所有班级（选「活动工作表」只打当前班级）。

表格已设好 A4、四边 2 厘米、每页重复表头，直接打印即可。

8常见问题

  • 双击 exe 没反应 / 被 Windows 拦：点界面顶部「用网页版」链接；或直接用 Edge / Chrome 打开网页版 HTML。
  • 双击网页版用记事本打开了：右键文件 →「打开方式」→ 选 Edge / Chrome。
  • 浏览器没自动下载：看右上角「已阻止下载」点「保留」；或点页面里的「手动保存」链接。
  • 选了年级却没勾班级：说明该年级下没有班级（或名册年级列是空的），看「名册自检」提示。
  • 搜索找不到班级：关键字要是班级名里的字（如「机器人」「会计」），不是学号；搜到后点「全选匹配项」。
  • 数据会不会上传：不会。网页版全程不联网；exe 版只在你本机运行。

9环境要求

  • 网页版：任意现代浏览器（Edge / Chrome / 360 / QQ），无需安装、无需网络。
  • exe 版：Windows；若被杀软拦截，优先改用网页版。
  • 名册：教务处导出的 Excel，需含「学号、姓名、班级、上课院系、培养层次」列；按届别筛请含「入学年份」列。
